## LeRobot의 범위와 버전

**LeRobot**은 Hugging Face의 로봇 데이터 수집·모방학습·평가·배포 라이브러리입니다. ACT와 Diffusion Policy뿐 아니라 SmolVLA, π 계열, GR00T 같은 정책을 같은 도구 체계에서 다룹니다. 지원 정책마다 필요한 하드웨어·추가 패키지·데이터 표현이 다릅니다.

이 챕터는 **LeRobot 0.6.0**을 기준으로 합니다. 0.6부터 기본 `pip install lerobot`만으로 데이터셋·학습 의존성을 모두 설치하지 않습니다. 목적에 맞는 extra를 선택합니다. 0.5.1의 GR00T N1.5 경로와 0.6의 N1.7 경로도 구분합니다.

## 설치와 환경 점검

Python 3.12 환경과 선택한 PyTorch 빌드에 맞는 GPU 드라이버를 준비합니다. 다음 명령은 로컬 학습용 환경을 구성합니다.

```bash
python3.12 -m venv env_lerobot06
source env_lerobot06/bin/activate
python -m pip install --upgrade pip
python -m pip install "lerobot[training]==0.6.0"
lerobot-train --help
```

비디오 처리는 TorchCodec·FFmpeg 조합을 따로 확인합니다. 배포판에 설치된 FFmpeg가 항상 호환되는 것은 아닙니다. Python·PyTorch·TorchCodec·FFmpeg 버전을 기록하고, 실제 데이터에서 한 프레임을 읽은 뒤 장시간 학습을 시작합니다. Jetson의 aarch64 경로는 x86_64 설치 명령을 그대로 복사하지 않습니다.

## LeRobotDataset v3

데이터셋 v3는 **상태·행동을 Parquet**, 카메라 프레임을 MP4, 구조와 통계를 메타데이터로 저장합니다. 데이터셋 포맷 버전은 라이브러리 버전 번호와 별개입니다.

```text
데이터셋 v3의 논리 구조
meta/info.json          포맷 버전, fps, 특성, 파일 경로 템플릿
meta/stats.json         관측·행동 통계
meta/episodes/          Parquet 형식 에피소드 메타데이터와 오프셋
data/                   여러 에피소드를 담는 Parquet 파일
videos/                 카메라별로 여러 에피소드를 담는 비디오 파일
```

v2의 `episode_000000.parquet`·`episode_000000.mp4` 한 쌍이 에피소드 하나라는 가정을 v3에 적용하지 않습니다. v3는 더 큰 파일에 여러 에피소드를 묶고 메타데이터 오프셋으로 구간을 찾습니다. 경로를 직접 조립하기보다 데이터셋 API를 사용합니다.

```python
from lerobot.datasets import LeRobotDataset

repo_id = "lerobot/aloha_sim_insertion_scripted"
dataset = LeRobotDataset(repo_id)
frame = dataset[0]
print(dataset.meta.fps)
print(frame["observation.state"].shape)
print(frame["action"].shape)
```

이 예제는 Hub 데이터 다운로드와 비디오 디코딩 환경이 필요합니다. 데이터셋 revision과 포맷 호환성을 기록합니다. 정책마다 요구하는 카메라 키가 다르므로 임의로 `camera_0`로 바꾸지 않습니다.

## 시간 창과 행동 청크

ACT(Action Chunking Transformer)는 여러 미래 행동을 한 번에 예측합니다. `delta_timestamps`의 단위는 **프레임 번호가 아닌 초**입니다. 50프레임의 행동 청크를 구성할 때는 데이터의 실제 fps로 나눕니다.

```python
from lerobot.datasets import LeRobotDataset, LeRobotDatasetMetadata

repo_id = "lerobot/aloha_sim_insertion_scripted"
metadata = LeRobotDatasetMetadata(repo_id)
fps = metadata.fps
dataset = LeRobotDataset(
    repo_id,
    delta_timestamps={
        "observation.state": [0.0],
        "action": [i / fps for i in range(50)],
    },
)
```

`[0, 1, 2, ...]`를 넣으면 연속 프레임 대신 0초·1초·2초 뒤의 행동을 요청합니다. 에피소드 끝 패딩과 마스크도 손실 계산에서 처리해야 합니다.

## 명령줄 학습

아래 예시는 공개 시뮬레이션 데이터로 ACT를 학습하는 로컬 경로입니다. Hub 업로드와 외부 실험 로깅은 비활성화합니다.

```bash
lerobot-train \
  --dataset.repo_id=lerobot/aloha_sim_insertion_scripted \
  --policy.type=act \
  --policy.device=cuda \
  --policy.push_to_hub=false \
  --output_dir=outputs/train/act_insertion \
  --job_name=act_insertion \
  --steps=1000 \
  --batch_size=8 \
  --wandb.enable=false
```

`--steps`와 `--batch_size`는 최상위 학습 설정입니다. 과거 예제의 `--training.num_epochs`·`--training.batch_size`를 사용하지 않습니다. 1000스텝은 실행 경로를 점검하기 위한 예시이며 성능 목표가 아닙니다. 관측 특성·정규화·행동 처리기를 공식 학습 파이프라인이 구성하도록 합니다.

0.6은 평가 설정의 `eval_freq`를 `env_eval_freq`로 바꿨습니다. 예전 설정 파일을 그대로 재사용하지 말고 설치한 버전의 `--help`와 대조합니다.

## 평가와 실제 로봇 연결

오프라인 손실은 실제 과제 성공률과 다릅니다. 학습에 사용하지 않은 에피소드·초기 위치·물체·언어 지시로 평가하고 데이터 누출을 피합니다. 실제 배포는 0.6의 `lerobot-rollout`과 해당 로봇 플러그인 문서를 따릅니다.

SO-100·SO-101은 리더·팔로워 구성을 지원하는 저가 로봇 팔입니다. ACT를 쓸 수 있다는 사실만으로 임의의 관절 순서·카메라·서보 보정이 호환되는 것은 아닙니다. 모터 보정과 한계값, 행동 단위, 제어 주파수를 먼저 맞춥니다.

GR00T 참조 구현은 LeRobot v2 기반에 `meta/modality.json`을 추가한 포맷을 사용합니다. 최신 LeRobot v3 데이터셋을 변환 없이 GR00T에 전달하지 않습니다. 변환 후 에피소드 경계·카메라 시각·상태/행동 차원을 다시 비교합니다.
