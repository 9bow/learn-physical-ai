## 월드 모델과 물리 시뮬레이터의 차이

**월드 파운데이션 모델(WFM)**은 관측·언어·행동 등에서 미래 영상이나 다른 출력을 생성하는 모델입니다. 학습 데이터의 패턴을 활용하므로, 물리 방정식의 해를 계산하는 Isaac Sim·MuJoCo와 오차 특성이 다릅니다. 영상이 자연스럽다는 사실은 접촉·힘·충돌의 정확성을 보증하지 않습니다.

NVIDIA Cosmos는 이 모델과 데이터 정제·후학습·평가 도구를 제공하는 플랫폼입니다. 2026-10-23 확인 기준 현재 제품군은 **Cosmos 3**입니다. Predict2.5·Transfer2.5·Reason 계열은 이전 세대의 역할을 이해하거나 기존 실험을 재현하는 맥락으로 구분합니다. Predict2.5 저장소는 제한적 유지보수와 Cosmos 3로의 이동을 안내합니다.

## Cosmos 3의 구성

Cosmos 3는 통합 Mixture-of-Transformers 구조에서 두 역할을 구분합니다.

| 구성 | 입력 | 출력과 용도 |
|---|---|---|
| Reasoner | 텍스트·영상 | 텍스트, 장면 이해·근거 연결·계획 |
| Generator | 텍스트·영상·오디오·행동 | 영상·오디오·행동, 예측·증강·정책 학습 |

기본 모델은 Super 64B, Nano 16B, Edge 4B로 나뉩니다. 모델 크기만으로 제어 주파수나 VRAM을 예측하지 않습니다. 입력 해상도·길이·출력 모달리티·정밀도·후학습 체크포인트에 따라 실행 비용이 달라집니다.

```text
실제 데이터 / 시뮬레이터 데이터
             │
             ▼
Curator: 정제·분할·중복 및 품질 관리
             │
             ▼
Cosmos: 추론 또는 태스크별 후학습
             │
             ▼
Evaluator + 실제 태스크 평가
             │
             ▼
정책 학습에 사용할 데이터 선별
```

2026년 10월 공개 예제에는 주행·양팔 로봇의 상호작용 시뮬레이션 체크포인트가 포함됩니다. 이는 특정 입출력과 후학습 조건을 가진 예제입니다. 임의의 기본 모델에 로봇 관절 명령을 넣으면 정확한 다음 상태를 얻는다는 뜻은 아닙니다.

## 이전 세대와 읽는 방법

Predict2.5는 Text2World·Image2World·Video2World와 로봇 행동 조건부 모델을 제공했습니다. Transfer 계열은 깊이·분할·엣지 등 구조 조건을 활용한 영상 변환에 쓰였습니다. Reason 계열은 장면과 동작을 텍스트로 추론하는 역할입니다.

토크나이저는 영상을 압축된 잠재 표현으로 바꾸는 구성 요소입니다. 초기 Cosmos의 이산·연속 토크나이저 설명을 모든 세대의 동일한 API나 학습 방식으로 일반화하지 않습니다. 재현할 논문의 모델 세대·체크포인트·코드 revision을 함께 기록합니다.

## 합성 데이터의 올바른 사용

Isaac Sim이 만든 동일 궤적의 RGB·깊이·분할 출력에서 외관을 다양화하는 흐름을 생각해 봅니다. 생성 모델이 배경·조명을 바꾸는 동안 물체 위치나 로봇 손 모양까지 바꿀 수 있습니다. 원래의 행동·분할·포즈 레이블이 여전히 맞는지 검사해야 합니다.

데이터 증강 전후에 카메라 시점·물체 추적·접촉 시각을 비교합니다. 행동 레이블과 맞지 않는 표본은 학습에서 제외합니다. 실제 평가 세트는 생성 모델 입력이나 후학습 데이터와 분리합니다.

생성형 시뮬레이션을 정책 평가에 사용할 때는 **모델 오차를 정책 성공으로 오해하는 현상**도 검사합니다. 실제 실패를 성공 영상으로 생성하거나, 정책이 모델의 빈틈을 이용할 수 있습니다. 물리 시뮬레이터와 실물 실험을 함께 사용하고 충돌·힘·성공 판정의 기준을 명시합니다.

## 실행 경로와 자원

Cosmos 3 공식 quickstart는 별도 Python 3.13 환경과 `Cosmos3OmniPipeline`, `nvidia/Cosmos3-Nano` 경로를 안내합니다. Isaac Lab 3.0·GR00T의 Python 3.12 환경에 그대로 합쳐 설치하지 않습니다. 세대별 Cookbook과 환경 지침을 사용합니다.

일부 guardrail·백본 저장소는 모델 접근 조건에 대한 동의와 계정 인증이 필요합니다. 첫 실행은 큰 체크포인트를 다운로드하므로 VRAM·디스크·네트워크 요구사항을 먼저 확인합니다. API 호출 예시와 로컬 가중치 실행 예시의 비용도 구분합니다.

## 라이선스와 검증 범위

이전 Predict2.5의 코드는 Apache 2.0, 모델은 NVIDIA Open Model License로 구분됩니다. Cosmos 3도 사용할 정확한 모델 카드와 의존 guardrail·데이터 조건을 확인합니다. 연구용·비상업용으로만 공개되었다고 일괄 단정하지 않습니다.

데모·벤치마크·자체 태스크 검증을 구분해서 기록합니다. 월드 모델은 데이터 다양화와 연구용 평가에 도움을 주지만, 생성 영상만으로 실물 로봇의 안전이나 일반화 성능을 입증할 수 없습니다.
