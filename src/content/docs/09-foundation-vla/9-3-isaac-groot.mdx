## GR00T의 목적과 공개 범위

**NVIDIA Isaac GR00T**는 여러 로봇 구조에서 시각·언어·상태를 행동으로 연결하는 VLA 프로젝트입니다. 휴머노이드 조작을 주요 대상으로 하지만 공개 체크포인트와 예제에는 로봇 팔도 포함됩니다. 조작 정책을 로드한다고 보행·균형·전신 안전 제어가 자동으로 해결되지는 않습니다.

2026-10-23 확인 기준 공식 저장소는 **GR00T N1.7 GA**를 안내합니다. N1은 최초 공개 모델이라는 역사적 의미로 구분합니다. N1.5·N1.6의 데이터 설정과 스크립트를 N1.7 체크포인트에 임의로 조합하지 않습니다.

가중치·참조 코드·추론·사용자 데이터 파인튜닝·배포 도구가 공개되어 있습니다. 따라서 전체 파이프라인을 사용할 수 없는 폐쇄형 제품이라는 설명은 현재 공개 범위와 맞지 않습니다. 다만 공개 코드와 사전학습 데이터 전체의 공개는 별개입니다.

## N1.7 아키텍처와 행동 표현

```text
카메라 이미지 + 언어 + 로봇 상태
             │
             ▼
Cosmos-Reason2-2B / Qwen3-VL 계열 VLM
             │
             ▼
Flow-matching diffusion transformer 행동 헤드
             │
             ▼
로봇 설정에 맞는 행동 청크
             │
             ▼
좌표·단위 변환 + 제어기 + 안전 제한
```

N1.7은 N1.6의 Eagle 백본에서 Cosmos-Reason2 계열로 바뀝니다. 상대 엔드이펙터 행동 공간을 사용하며, 행동 표현과 상태 키는 embodiment 설정으로 지정합니다. 모델 출력이 항상 관절 토크나 전체 몸체 궤적이라는 뜻은 아닙니다.

행동 청크의 예측 길이와 한 번에 실행하는 길이는 구분합니다. N1.7의 CLI는 `--execution-horizon`으로 실제 실행 구간을 지정합니다. 관측이 오래된 상태에서 긴 행동 청크를 끝까지 실행하면 외란 대응이 늦어질 수 있습니다.

## 설치와 첫 추론

GR00T는 Isaac Lab 환경과 **별도의 Python 3.12 환경**으로 구성합니다. 공식 저장소에서 사용한 commit을 기록하고 해당 commit의 lockfile을 사용합니다. CUDA·PyTorch·TensorRT 조합은 dGPU·Orin·Thor별 배포 표를 따릅니다.

```bash
git clone https://github.com/NVIDIA/Isaac-GR00T.git
cd Isaac-GR00T
git rev-parse HEAD
uv sync --python 3.12
uv run python -c "import gr00t; print(gr00t.__file__)"
```

N1.7이 불러오는 `nvidia/Cosmos-Reason2-2B` 백본은 접근 승인이 필요한 gated 모델입니다. 모델 페이지에서 조건에 동의하고 승인을 받은 계정으로 인증해야 합니다. 로그인만으로 접근 권한이 생기지는 않습니다.

공식 DROID 샘플로 **오픈 루프 추론**을 먼저 실행합니다. 다음 명령은 저장된 관측에 대한 예측이며 실제 로봇 제어를 수행하지 않습니다.

```bash
uv run python scripts/deployment/standalone_inference_script.py \
  --model-path nvidia/GR00T-N1.7-3B \
  --dataset-path demo_data/droid_sample \
  --embodiment-tag OXE_DROID_RELATIVE_EEF_RELATIVE_JOINT \
  --traj-ids 1 2 \
  --inference-mode pytorch \
  --execution-horizon 8
```

샘플 추론이 성공해도 새 로봇으로의 제로샷 전이를 입증하지 않습니다. 카메라 구성·상태·행동 공간이 다르면 로봇 설정과 파인튜닝이 필요합니다.

## 데이터와 파인튜닝

참조 구현은 **LeRobot v2 계열 데이터 + `meta/modality.json`**을 사용합니다. modality 파일은 연결된 상태·행동 벡터를 어떤 필드로 나눌지, 어떤 비디오 키를 사용할지 정의합니다. 일반 HDF5·RLDS 또는 LeRobot v3를 그대로 전달하지 않습니다.

| 항목 | 확인할 내용 |
|---|---|
| embodiment tag | 기존 학습 로봇인지, `NEW_EMBODIMENT`인지 |
| 상태와 행동 | 관절/EE 표현, 상대·절대 좌표, 순서, 단위 |
| 비디오 | 카메라 이름, 프레임레이트, 시간 정렬 |
| 정규화 | 데이터 통계와 체크포인트 설정의 일치 |
| 평가 분리 | 같은 시연의 인접 프레임이 학습·평가에 섞이지 않음 |

사용자 로봇은 공식 `gr00t/experiment/launch_finetune.py`와 modality 설정을 사용합니다. [휴머노이드 VLA 통합 프로젝트](../../12-projects/12-4-humanoid-vla/)에서 실제 공개 진입점을 연결합니다.

## Isaac Sim·Lab·Cosmos의 역할

Isaac Sim은 장면·센서·접촉을 시뮬레이션합니다. Isaac Lab과 Mimic 계열 도구는 태스크 실행·원격 조작·시연 증강에 활용됩니다. GR00T 자체의 공개 학습 경로는 시연 기반 파인튜닝이며, Isaac Lab PPO를 실행하는 것과 구분합니다.

합성 비디오만으로는 행동 레이블이 생기지 않습니다. 리타게팅·시뮬레이션 시연·모션 계획으로 유효한 행동을 만들고, 생성 영상이 그 행동과 일관되는지 검사해야 합니다. 모델이 생성한 영상에서 충돌·파지가 그럴듯해 보여도 실제 접촉을 보증하지 않습니다.

## 배포와 라이선스

N1.7은 ONNX·TensorRT 내보내기와 서버·클라이언트 추론 경로를 제공합니다. 공개 지연 수치는 특정 하드웨어·배치·태스크 조건의 결과입니다. 자체 장비에서 전처리·통신·행동 청크 실행까지 포함한 지연과 성공률을 다시 측정합니다.

N1.7 공식 안내는 Apache 2.0 라이선스를 명시합니다. 백본·데이터·에셋 등 의존 구성 요소와 이전 GR00T 릴리스의 조건은 각각 확인합니다. 공개 모델 사용권과 안전한 실물 로봇 배포의 검증은 서로 다른 문제입니다.
