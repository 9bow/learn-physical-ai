## 3.0과 2.x의 설치 경로 구분

**Isaac Lab 3.0.0은 2026-10-20 정식 공개**되었습니다. 새 프로젝트는 버전 태그를 고정한 3.0 설치 경로를 검토합니다. 기존 코스의 `ManagerBasedRLEnvCfg`, Torch 텐서 직접 접근, `isaaclab.sh` 예제는 **2.3.2 재현 경로**입니다. 설치 명령만 3.0으로 바꾸면 기존 코드가 그대로 동작하지 않습니다.

| 항목 | Isaac Lab 3.0.0 | 기존 예제: Isaac Lab 2.3.2 |
|---|---|---|
| Python | 3.12 | Sim 5.1 조합은 3.11 |
| 실행 도구 | `uv run isaaclab` | `./isaaclab.sh -p` |
| 물리 백엔드 | Newton, OVPhysX, Isaac Sim PhysX 등 | Isaac Sim / PhysX |
| Isaac Sim 의존성 | 선택 사항, 사용 시 6.2 대상 | 이 코스는 Sim 5.1로 고정 |
| 쿼터니언 | `(x, y, z, w)` | `(w, x, y, z)` |
| 자산·센서 데이터 | `ProxyArray`, `.torch`/`.warp` 명시 | `torch.Tensor` |

`main`·`develop`·이동하는 release 브랜치를 임의로 클론하지 않습니다. 소스 태그, Python, 시뮬레이터, RL 라이브러리를 하나의 재현 단위로 기록합니다. 2.3.2 + Sim 5.1은 기존 API를 설명하기 위한 조합이며, 현재 지원되는 최신 운영 환경이라는 뜻은 아닙니다.

## 새 프로젝트: Isaac Lab 3.0

Ubuntu와 Python 3.12, NVIDIA GPU 드라이버가 준비된 머신에 `uv`를 설치합니다. 아래 명령은 Isaac Lab 3.0 공식 CLI 구조를 따릅니다.

```bash
git clone --branch v3.0.0 --depth 1 https://github.com/isaac-sim/IsaacLab.git
cd IsaacLab
uv run isaaclab train \
  --rl_library rsl_rl \
  --task Isaac-Cartpole \
  physics=newton_mjwarp \
  --viz newton_gl
```

이 경로는 Newton 기반이며 Isaac Sim을 시작하지 않습니다. 디스플레이가 없는 서버에서는 선택한 시각화 백엔드의 헤드리스 실행 지침을 적용합니다. 물리·렌더링·시각화는 별도 설정이므로 `--headless`를 구버전에서 복사하지 않습니다.

Isaac Sim ROS Bridge나 Kit 도구가 필요한 경우에는 `isaacsim` extra를 선택합니다.

```bash
uv run --extra isaacsim isaaclab train \
  --rl_library rsl_rl \
  --task Isaac-Cartpole \
  physics=isaacsim_physx \
  --viz kit
```

Isaac Sim 백엔드의 RTX 하드웨어 요구사항은 [설치와 시스템 요구사항](../../04-isaac-sim/4-1-installation-requirements/)을 따릅니다. Newton 경로의 요구사항을 Isaac Sim 요구사항과 같다고 가정하지 않습니다.

## 기존 예제 재현: Isaac Lab 2.3.2

다음 절차는 **Ubuntu x86_64, Python 3.11, Isaac Sim 5.1** 전용입니다. 3.0 환경과 분리합니다. Omniverse Launcher는 지원 종료되었으므로 사용하지 않습니다.

```bash
python3.11 -m venv env_isaaclab232
source env_isaaclab232/bin/activate
python -m pip install --upgrade pip
python -m pip install "isaacsim[all,extscache]==5.1.0" --extra-index-url https://pypi.nvidia.com
python -m pip install torch==2.7.0 torchvision==0.22.0 --index-url https://download.pytorch.org/whl/cu128
git clone --branch v2.3.2 --depth 1 https://github.com/isaac-sim/IsaacLab.git
cd IsaacLab
./isaaclab.sh --install rsl_rl
```

`isaaclab.sh`는 활성 가상환경 또는 연결된 Isaac Sim Python을 선택합니다. 항상 번들 Python만 사용한다는 설명은 pip 설치 경로에는 맞지 않습니다. GLIBC 2.35 이상, 호환 드라이버, 사용 가능한 에셋 다운로드 경로도 필요합니다.

## 설치와 첫 학습 검증

2.3.2 저장소 루트에서 빈 시뮬레이션과 로봇 자산을 각각 실행합니다. 헤드리스 예제는 계속 실행될 수 있으므로 초기화·스텝 로그를 확인한 뒤 종료합니다.

```bash
./isaaclab.sh -p scripts/tutorials/00_sim/create_empty.py --headless
./isaaclab.sh -p scripts/tutorials/01_assets/run_articulation.py --headless
```

첫 학습은 환경 수와 반복 수를 작게 설정합니다.

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Cartpole-v0 \
  --num_envs 64 \
  --max_iterations 10 \
  --headless
```

초기 smoke test는 설치·샘플 수집·업데이트·체크포인트 저장 경로를 검사합니다. 10회 반복만으로 충분한 정책 성능이 확보된다는 뜻은 아닙니다. 로그 경로를 기록하고, 실제 생성된 체크포인트를 평가 명령에 전달합니다.

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Cartpole-v0 \
  --num_envs 32 \
  --checkpoint /absolute/path/to/model_10.pt
```

카메라 태스크는 2.x에서 `--enable_cameras`를 추가합니다. 비디오 녹화도 렌더링을 사용하므로 VRAM·실행 속도를 다시 측정합니다. 헤드리스 실행에 Xvfb가 항상 필요한 것은 아닙니다.

## 3.0 마이그레이션 검증

3.0은 태스크 식별자·환경 구성·명령줄 구조도 바꿉니다. `Isaac-Cartpole-v0`를 새 CLI에 그대로 넘기지 않습니다. `isaaclab.sh`는 사용 중단 예정이며 새 워크플로는 `uv`를 사용합니다.

쿼터니언은 초기 자세·리셋·목표·관측을 모두 XYZW로 옮깁니다. 항등 회전은 `(1, 0, 0, 0)`에서 `(0, 0, 0, 1)`로 바뀝니다. 자산 상태는 `robot.data.root_pos_w.torch`처럼 접근하며, 시뮬레이터에 쓰는 인덱스와 마스크도 새 API에 맞춥니다.

버전 이동 후에는 같은 초기 상태에서 관측 차원·좌표계·접촉·종료 조건을 비교합니다. 기존 체크포인트를 새 환경에 로드할 수 있다는 사실만으로 동작 동등성이 입증되지는 않습니다.
